# CodeSef Website

Static multi-page corporate website based on the supplied CodeSef brief and logo.

## Run locally
Open `index.html` in a browser, or serve the folder with a local web server.

## Structure
- `index.html`
- `about.html`
- `services.html`
- `portfolio.html`
- `contact.html`
- `services/*.html` — individual service pages
- `portfolio/*.html` — individual placeholder case studies
- `assets/codesef-logo.jpeg` — supplied logo
- `assets/styles.css`
- `assets/site.js`

## Before production
Replace placeholder contact details, social links, company metrics, project content, and connect the contact form to a real backend/email service.
